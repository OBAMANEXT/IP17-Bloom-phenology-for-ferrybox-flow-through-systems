# IP17 - Bloom phenology for ferrybox flow through systems

The purpose of this package is to provide the means to analyse plankton spring blooms
from chlorophyll-a fluorometer measurements. This package is still in
development and might see some changes in the future. In addition some of the
definitions and measurements used might undergo changes.

> [!NOTE]
> The code repository for this IP is maintained at 
> [https://gitlab.com/sehrhart/bloomphen](https://gitlab.com/sehrhart/bloomphen).
